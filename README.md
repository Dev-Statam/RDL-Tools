# RDL Tools

Extension navigateur destinée aux salariés RD Lyon ayant accès au site Service Voiture En Mobilité.

Elle permet de générer des fichiers ICS à partir des journées de travail et de repos affichées par Service Voiture, afin de les enregistrer dans vos agendas personnels.
